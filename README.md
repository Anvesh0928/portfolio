# Anvesh Tiwari - Personal Portfolio Website

Welcome to my personal portfolio repository! This is a simple, beginner-friendly personal portfolio website created using fundamental web development technologies (**HTML5** and **CSS3**).

---

## 📌 Project Overview

This portfolio website showcases my profile, technical skills, projects, educational background, and contact information. It is designed to be clean, readable, and easy to maintain.

---

## 🛠️ Technologies Used

- **HTML5**: For semantic structure and web elements.
- **CSS3**: For styling, page layout, and visual presentation (styled using named CSS colors for easy understanding).


## 📂 Project Structure

text
Portfolio/
├── index.html        # Main HTML file containing webpage content
├── style.css         # CSS stylesheet for styling the portfolio
├── ProfilePhoto.jpeg # Profile picture
└── README.md         # Documentation for the project
```

---

## 📄 Website Sections

1. **Header & Navigation**: Displays the name, job title, and quick navigation links.
2. **About Me**: Brief intro and profile picture.
3. **Skills**: List of technical skills (HTML, CSS, JavaScript, React.js, Node.js, Express.js, GitHub).
4. **Projects**: Showcase of projects with live view links.
5. **Education**: Educational details presented in a structured table.
6. **Contact Me**: Interactive contact form for messages.
7. **Footer**: Social profiles and direct contact links (Email, GitHub, LinkedIn).

## 🚀 How to Run the Project

1. Download or clone this repository to your local computer.
2. Open the project folder.
3. Double-click on `index.html` (or right-click and choose **Open with** -> your preferred web browser like Chrome, Edge, or Firefox).
